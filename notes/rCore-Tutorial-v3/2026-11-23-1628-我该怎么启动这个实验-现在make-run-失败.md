## Q1 · 16:29 · 我该怎么启动这个实验，现在make run 失败

我该怎么启动这个实验，现在make run 失败

### A1 · 16:29

我已在你机器上实测过：这个项目**编译和运行都是正常的**，失败的几乎肯定是目录不对。

## 原因

`make run` 这个目标（`run-inner`）只定义在 **`os/Makefile`** 里。仓库根目录的 `Makefile` 只有 `docker`、`build_docker`、`fmt` 三个目标：

```
$ cd /home/cgh/github/rCore-Tutorial-v3 && make run
make: *** No rule to make target 'run'.  Stop.     ← 你看到的报错
```

## 正确启动方式

```bash
cd /home/cgh/github/rCore-Tutorial-v3/os
make run
```

我实测的输出（已进内核、进用户 shell）：

```
Platform: qemu
/**** APPS ****  ... (hello_world, usertests, ...) ****/
Rust user shell
>> 
```

在 `>>` 后面直接敲命令即可，例如：

```
>> hello_world
>> usertests
```

